# noriba
 
Aplikasi panduan bagi yang terlilit utang berbunga (pinjol, paylater, dan sejenisnya), dari [jalanberkah.my.id](https://jalanberkah.my.id).
 
Situs: https://noriba.jalanberkah.my.id
 
## Isi
 
- **Peta Utang**: hitung rasio cicilan, perkiraan lunas, dan urutan pelunasan.
- **Pustaka**: fatwa, tanya jawab, catatan hijrah, nasihat keuangan, motivasi, serta doa dan dzikir.
- **Laporan**: ringkasan yang bisa dicetak atau disimpan sebagai PDF.
## Privasi
 
Semua data tersimpan hanya di peramban pengguna (localStorage). Tidak ada akun, server, pelacak, atau permintaan jaringan keluar.
 
## Catatan
 
Aplikasi ini bukan fatwa dan bukan nasihat keuangan atau hukum. Untuk kasus pribadi, tanyakan kepada ustaz yang berilmu.
 
## Teknis
 
Satu berkas statis (`index.html`) tanpa dependensi atau proses build. Di-host dengan GitHub Pages.
